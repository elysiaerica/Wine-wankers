# Agent Workflow

## Pre-Execution Context

Before starting work, reference:

→ Notion dashboard (strategy + priorities)
→ /docs/section_map.md (structure)

Notion informs intent.
Repository controls execution.

When working in this repository, agents must follow this workflow.

---

## Step 1

Read:

```
/docs/section_map.md
```

---

## Step 2

Identify the section to modify.

---

## Step 3

Open only the relevant files:

```
/components/{section}.html
/source/style_guide/{version}.html
```

Do not open the entire repository.

---

## Step 4

Update the component.

---

## Step 5

Insert the component into:

```
/master/style_guide_FINAL.html
```

---

## Rule

Never modify multiple components in one operation.
