01.5 Strategic Rationale

Why Spectrum Won

Three viable territories were evaluated against Wine Wankers' positioning goals, community makeup, and founder vision. One was selected. Two were rejected.

Territory A — Rejected

Suits, Hipsters, Everyone

Eclectic, inclusive, broad direction. Strong execution risk — without a visual signature, the brand reads as another generic wine subscription. No ownable territory, no community signal.

Territory B — Selected ✓

The Rainbow Direction

Makes Nick's existing rainbow identity ownable and intelligent. Executed as optical science — refraction bars, prismatic light, chromatic displacement on "weird". The spectrum reads as pride, science, and counterculture simultaneously without being literal. This is the brand.

Territory C — Rejected

Natty Wine Eclectic

Hand-drawn, lo-fi, zine aesthetic. Better suited for Chasing Rainbows Wine Co. as a standalone retail brand. Lacks the visual authority and scalability needed for Wine Wankers as a community platform.

Why Spectrum Works

The Spectrum direction transforms a rainbow — already part of Nick's existing visual language — into an optical phenomenon. Refraction bars as the brand signature. Chromatic displacement on "weird" as the hero typographic effect. Dark backgrounds as the premium canvas. The system reads as a distinct, ownable visual identity that no competitor in the natural wine space has claimed.

05 Rainbow Stack Rule

The Rainbow Stack

Layered text-shadow that creates chromatic displacement — the brand's primary typographic signature.

Only "weird" receives the rainbow stack

"good wine." is plain cream. "people." is plain cream. Only the word "weird" in the hero title gets rainbow text-shadow. This is a locked decision and may not be changed.

CSS implementation — exact selector required

.hero-title span.rainbow-stack { text-shadow: 2px 2px 0 #e84545, 4px 4px 0 #f5a623, 6px 6px 0 #f7dc6f, 8px 8px 0 #52be80, 10px 10px 0 #48c9b0, 12px 12px 0 #2db5e8, 14px 14px 0 #af7ac5; }

Do

Apply .rainbow-stack to the word "weird" inside .hero-title. Selector must be .hero-title span.rainbow-stack — not .hero-title directly.

Don't

Apply rainbow-stack to "wine", "people", .hero-title directly, section headings, body text, or any element other than the single word "weird".

06 UX Components

Approved Interaction Systems

Five interaction systems only. Do not introduce additional glow systems, animated logos, or text effects beyond these.

1 — Ethereal Hero Background

Low-intensity atmospheric colour via radial gradients + conic-gradient prism. Hero section only. Non-distracting. Elements: .hero-bg (radial gradients) + .hero-prism / .hero-prism-glow / .hero-prism-hot (conic, top-right).

2 — Glow Button (Rainbow CTA Hover)

Applies to: hero CTA, event buttons, footer signup. Default: calm yellow fill, dark text. Hover: rainbow gradient border animates via ::before + gradient-shift keyframe. Opacity 0 at rest → 1 on hover. transform: translateY(-2px) on hover.

3 — Interactive Card Glow

Applies to: event cards, fridge/wine cards only. Pointer-proximity radial gradient via --glow-x/--glow-y CSS vars updated by JS mousemove. ::after pseudo-element. Directional and tactile — not a permanent static halo.

4 — Prism Border (Manifesto Section)

Manifesto inner wrapper uses gradient border: border:1px solid transparent + background:linear-gradient(deep,deep) padding-box, spectrum-gradient border-box. Visible spectrum frame without background fill.

5 — Reveal Animation

IntersectionObserver adds .visible class to .reveal elements. opacity:0 + translateY(30px) → opacity:1 + translateY(0) on enter. Stagger: .reveal-d1/d2/d3/d4 (transition-delay .1s/.2s/.3s/.4s). Apply will-change: transform, opacity to all .reveal elements.

06.5 Design System

System Rules

The structural layer beneath the visual layer. These rules ensure consistency across all touchpoints without requiring custom decisions each time.

Layout approach

Grid & Spacing

80px desktop margins. 8px base grid. 1200px max-width. border-radius: 2px throughout — not 4px, not 8px. Asymmetric layouts preferred over centred symmetry. Warmth over formality.

Border & line style

Subtle Edges

1px solid rgba(255,255,255,.07) on dark surfaces. 1px solid rgba(0,0,0,.08) on light surfaces. Never solid white or black borders. No drop shadows — depth handled by layered backgrounds only.

Texture & grain

Optional Noise

Optional 2–4% noise texture overlay on dark sections only. No gradients except the 7-colour spectrum system. Scribble layer: ghosted Instrument Serif italic word at opacity .035, 180–220px, dark sections only.

Motion notes

Light, Not Bounce

Fade-in 400ms ease. Stagger 50ms per beam element. No bounce, spring, or overshooting easing. Motion should feel like light changing — gradual, atmospheric, never mechanical.

Signature element — Refraction Bars

7 staggered bars · spectrum order · decreasing width · hero, section transitions, footers

Refraction bar placement rules

1. Hero sections — as the prism light-scatter signature element at base or side. 2. Section transitions between dark pages — not between light sections. 3. Special emphasis — footers, covers, closing statements. Do not use as repeating decorative pattern throughout body content.

07 Voice & Messaging

Tone of Voice

Anti-snob, not anti-expert

Disarms pretension. Does not dismiss knowledge — rejects gatekeeping. Warm, curious, slightly irreverent, never smug.

Community-first language

Lead with people, not product. "The room", "The Regulars", "weird people" — these are the story. Wine is the vehicle, belonging is the product.

09 Layout & Density

Layout Principles

High density, not generous whitespace

Tight padding signals difference from minimalist competitors. The page should feel like a packed bar — warm, full, alive.

Smooth scroll — no snap

html{scroll-behavior:smooth} only. No scroll-snap-type anywhere. The wine fridge uses overflow-x:auto without snap alignment. Sections flow fluidly.

Section flow — vertical narrative

No viewport-height locking. Padding-based sizing. Sections read naturally on scroll. Each section is a chapter in the brand story.

Spectrum strips as section dividers

Thin (2px, opacity .3) rainbow gradient lines breathe between sections. Decorative, not structural.

Content width

max-width approx 1200px, centered. Padding: clamp(20px,4vw,48px). Sections use consistent horizontal rhythm.

Mobile-first responsive

All sections readable and usable on mobile. Grid layouts collapse at 768px. Masonry: 3 cols → 2 cols at 768px → 1 col at 480px.

12 Brand Scaling

The Brand Ecosystem

Three entities in the Wine Wankers universe. Each has a defined visual and verbal relationship to the parent brand.

Primary brand

Wine Wankers

Full Spectrum direction. Dark backgrounds as primary environment. Refraction bars as signature element. Yellow CTA. Rainbow stack on "weird". Community-first, events-primary. Built to outgrow any single venue — the brand travels with the community.

Online store

Chasing Rainbows Wine Co.

Light mode for e-commerce. Aged Paper background (#f7f4ee). Wine Stain accents (#6b1a2a). Spectrum gradient strip as the connection to Wine Wankers. Same typography system — Syne, Instrument Serif, Newsreader, JetBrains Mono.

Host venue

The End Bar

Its own distinct visual identity — not a Wine Wankers sub-brand. Co-branded lockup only when hosting WW events. Refraction bars used as the "Presented by Wine Wankers" element. The End's identity remains independent and sovereign.

13 Community Engine

How the Movement Compounds

"The club is about 60% community and 40% wine. People keep coming back because of who they meet, not what they drink."
— Nick Goding, Founder · March 2026

The community engine is self-reinforcing. Each layer feeds the next. Events build community. Community drives subscriptions. Subscriptions fund events. The brand doesn't need to grow by spending more — it grows by making the existing community more visible to people who want to join it.

Operating now

Community → events → wine. Not the other way around.
